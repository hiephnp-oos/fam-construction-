## Evidence status
Reusable working principles, not verified project specifications, engineering designs, legal advice, current price data, or proof of tool capability. Verify external claims against current authoritative sources. Keep project records outside this folder.

## Maintenance
AI owns updates. Promote only reusable, evidence-supported learning through the repository learning loop.
