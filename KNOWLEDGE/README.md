## Evidence status
These documents synthesize recurring themes from prior FAM conversations. They are reusable working principles, not verified project specifications, engineering designs, legal advice, or current price data. Confirm technical, regulatory and commercial claims against current authoritative sources and project documents before relying on them.

## Maintenance
AI owns updates. Promote only reusable, evidence-supported learning through the repository learning loop. Keep client/project data, BOQs, quotations, contracts, drawings and identifiable records outside this folder.
