# BOQ and scope review
## Trigger
Compare BOQ with drawings, specifications, scope, revisions, or takeoffs.
## Method
1. Establish document versions/revisions and issued basis.
2. Map each BOQ item to drawing/specification evidence.
3. Compare description, unit, quantity, material, location, and inclusions.
4. Classify: match, quantity difference, missing, duplicate, description/spec mismatch, unclear scope, or revision mismatch.
5. Quantify only when source dimensions and calculation basis exist.
6. Do not assume document precedence; identify the discrepancy and request clarification if precedence is not established.
## Output
Discrepancy register: BOQ reference, source reference, issue, impact, evidence, action. Separate confirmed from potential discrepancies.
