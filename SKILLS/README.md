# Skills index and routing contract

Read only the skill(s) needed for the task. Use the skill description as a discovery hint, then read the full SKILL.md before applying it.

| User task | Load |
|---|---|
| Unit rate, cost build-up, estimate, construction pricing | [Estimating](estimating/SKILL.md) |
| Read drawing/PDF; extract material/specification schedule | [Drawing and material extraction](drawing-and-material-extraction/SKILL.md) |
| Compare BOQ, drawings, specifications, quantities, or scope | [BOQ and scope review](boq-and-scope-review/SKILL.md) |
| Contract clauses, obligations, variation, payment, delay, defects | [Contract analysis](contract-analysis/SKILL.md) |

If a task spans domains, load only the intersecting skills. Do not load construction skills for routine email rewriting, translation, or message replies unless technical reasoning materially changes the content. If no skill matches, use general reasoning and state relevant uncertainty; do not force-fit a skill.
