# Skill validation

These acceptance checks define expected behavior; they are not claims that tests have run. Record observed pass/fail and evidence when executed.

## Estimating
1. Missing location/date/source: label indicative; state assumptions/uncertainty.
2. Supply-only request: do not include installation silently.
3. Calculated total: reconcile rate × quantity and units.
4. AI visual guess without provenance: do not price as verified.

## Drawing and material extraction
1. Absent finish/brand: mark not specified.
2. Conflicting revisions: identify both; do not assume precedence.
3. Fixed columns: preserve schema and cite page/sheet/detail.
4. Scaled measurement: record calibration, region, method, unit and check.
5. Complex geometry/illegible scan: split into traceable parts or escalate.

## BOQ and scope review
1. Revision mismatch: classify and identify issued basis.
2. Item absent from one source: distinguish confirmed missing from unclear scope.
3. Uncalculable quantity: state limitation; do not invent.
4. Tool quantity: capture source, sheet/revision, region, scale, method/tool, unit, deductions and reviewer status.
5. Numeric reconciliation with incomplete coverage: do not claim full review.

## Contract analysis
1. Ambiguous clause: separate text, interpretation, assumption and missing information.
2. Notice/approval: identify exact clause/page and action/evidence.
3. Jurisdiction-dependent enforceability: no definitive legal conclusion.

## Routing
- Routine translation/email: no skill.
- BOQ-to-drawing: BOQ review; add drawing extraction for extraction/measurement.
- Drawing takeoff: drawing extraction + takeoff Knowledge; add BOQ review for scope reconciliation.
- Price build-up: estimating; add quantity skill if takeoff is involved.
- Contract payment/variation: contract analysis.

## Full-flow acceptance
A successful takeoff/BOQ test must show source/revision basis, traceable quantity method, escalation for complex geometry, BOQ mapping, discrepancy register, and no unsupported tool-use/completeness claim. Live test with actual PDFs is still required.
